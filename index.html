AI 연결

대화용 모델이 일반 대화를 맡고, 자료 검색용 모델이 웹 검색이 필요한 질문(최신 정보, 모르는 인물 등)에 DuckDuckGo 검색 결과를 붙여서 답해요. 아래 두 방식 중 하나를 골라주세요. 둘 다 실패하면 브라우저 안에서 바로 돌아가는 온디바이스 모델로 자동 전환돼요(키·서버 없이 항상 작동하고, GitHub Pages 같은 배포 사이트에서도 그대로 열려요).

내 컴퓨터에서 Ollama를 켜두고 쓸 거라면 내 컴퓨터를, GitHub Pages처럼 남도 접속하는 배포 사이트로 올릴 거라면 클라우드 API를 골라주세요. 클라우드 API 키는 이 브라우저에만 저장되고, 입력한 API 주소로 직접 요청이 나가요(중간 서버 없음).

대화용 모델

잡담·감정·일상 대화처럼 검색이 필요 없는 질문에 사용돼요. 대화용 또는 자료 검색용 모델 이름에 "deepseek"가 들어있으면, 채팅창에서 zip 파일을 첨부해 내용을 분석하거나 수정을 요청할 수 있는 실험적 기능도 함께 켜져요(압축 해제·해석 후 결과를 다시 zip으로 받을 수 있어요).

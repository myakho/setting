AI 모델

서버도, Ollama 설치도 필요 없어요. 이 브라우저 안에서 WebGPU로 직접 모델을 돌려요 (다운로드 후엔 인터넷 없이도 계속 동작하고, 대화 내용도 이 기기 밖으로 나가지 않아요). 그래서 데스크톱 앱은 물론, GitHub Pages 같은 정적 웹사이트로 열어도 그대로 동작해요. 대화용 모델이 일반 대화를 맡고, 자료 검색용 모델이 웹 검색이 필요한 질문(최신 정보, 모르는 인물 등)에 DuckDuckGo 검색 결과를 붙여서 답해요.

최신 Chrome 또는 Edge(버전 113 이상)가 필요해요. 지원 브라우저가 아니면 자동으로 가벼운 온디바이스 모델로 대체돼요. 처음 선택한 모델은 대화를 시작할 때 한 번만 다운로드되고, 이후엔 브라우저에 캐시돼서 바로 켜져요(모델 크기에 따라 수백 MB~수 GB).
아직 확인하지 않았어요. "테스트"를 눌러 WebGPU 사용 가능 여부를 확인해보세요.
대화용 모델

잡담·감정·일상 대화처럼 검색이 필요 없는 질문에 사용돼요. 모델 이름에 "deepseek"가 들어있으면, 채팅창에서 zip 파일을 첨부해 내용을 분석하거나 수정을 요청할 수 있는 실험적 기능도 함께 켜져요(압축 해제·해석 후 결과를 다시 zip으로 받을 수 있어요). 가벼운(용량이 작은) 모델일수록 다운로드가 빠르고 응답도 빨라요.

모델 선택
용량이 작을수록 빠르게 동작해요

모델 선택

비전(사진 설명)용 모델

채팅창에 사진을 첨부하면 이 모델이 사진을 보고 설명하거나 질문에 답해줘요. 하단 바의 화면 공유 버튼(🖥️)으로 실시간 화면 보기를 켰을 때도 이 모델이 그 순간의 화면을 같이 보고 답해요. 비워두면 사진 첨부·화면 공유 기능은 꺼져 있어요.

모델 선택
사진/화면을 이해할 수 있는 모델만 표시돼요

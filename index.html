AI 연결

대화용 모델이 일반 대화를 맡고, 자료 검색용 모델이 웹 검색이 필요한 질문(최신 정보, 모르는 인물 등)에 DuckDuckGo 검색 결과를 붙여서 답해요. 아래 두 방식 중 하나를 골라주세요. 둘 다 실패하면 브라우저 안에서 바로 돌아가는 온디바이스 모델로 자동 전환돼요(키·서버 없이 항상 작동하고, GitHub Pages 같은 배포 사이트에서도 그대로 열려요).

내 컴퓨터에서 Ollama를 켜두고 쓸 거라면 내 컴퓨터를, GitHub Pages처럼 남도 접속하는 배포 사이트로 올릴 거라면 클라우드 API를 골라주세요. 클라우드 API 모드는 키나 서버 없이 방문자의 브라우저에서 WebGPU로 직접 모델을 돌려요.

대화용 모델

잡담·감정·일상 대화처럼 검색이 필요 없는 질문에 사용돼요. 대화용 또는 자료 검색용 모델 이름에 "deepseek"가 들어있으면, 채팅창에서 zip 파일을 첨부해 내용을 분석하거나 수정을 요청할 수 있는 실험적 기능도 함께 켜져요(압축 해제·해석 후 결과를 다시 zip으로 받을 수 있어요).

최신 정보·사실 확인이 필요한 질문에서 DuckDuckGo 검색 결과와 함께 사용돼요.

모델 이름
예: qwen3.5:9b
비전(사진 설명)용 모델 (실험적)

채팅창에 사진을 첨부하면 이 모델이 사진을 보고 설명하거나 질문에 답해줘요. Ollama의 비전(멀티모달) 모델인 llava, minicpm-v 등을 이용해요. 비워두면 사진 첨부 기능은 꺼져 있어요.

모델 이름
예: llava
먼저 터미널에서 ollama pull llava 또는 ollama pull minicpm-v 로 모델을 받아주세요. Windows·macOS·Linux 어디서나 바로 쓸 수 있어요.
아직 테스트하지 않았어요. 서버 주소를 확인하고 테스트를 눌러보세요.
먼저 컴퓨터에 Ollama 설치 ↗ 후, 터미널에서
ollama pull exaone3.5:7.8b, ollama pull qwen3.5:9b 로 모델을 받아주세요.
이 웹앱에서 접속하려면 CORS를 허용해서 실행해야 해요
OLLAMA_ORIGINS=* ollama serve
터미널(또는 PowerShell)에 붙여넣고 엔터를 누르면 CORS가 허용된 채로 Ollama가 실행돼요.
macOS는 다운로드 후 실행 권한이 필요할 수 있어요(최초 1회 chmod +x 또는 마우스 오른쪽 클릭 → 열기). 터미널 명령을 직접 실행하는 건 브라우저 보안 정책상 불가능해서, 복사하거나 스크립트를 받아 실행해주세요.

이 모드는 서버나 API 키 없이 방문자의 브라우저에서 WebGPU로 직접 AI 모델을 돌려요. GitHub Pages 같은 배포 사이트에 그대로 올려도 누구나 바로 쓸 수 있어요. 잡담·감정·일상 대화는 바로 답하고, 최신 정보·사실 확인이 필요한 질문은 DuckDuckGo 검색 결과를 함께 참고해서 답해요.

브라우저 지원 확인
아직 확인하지 않았어요
최초 1회는 모델 파일(수백MB)을 내려받느라 시간이 걸릴 수 있어요. 이후에는 브라우저 캐시에서 바로 불러와요. WebGPU를 지원하지 않는 브라우저(예: 구형 Safari)에서는 자동으로 더 느린 CPU 모드로 대체돼요.
사진 첨부(비전) 기능은 이 모드에서는 아직 지원하지 않아요. 사진 설명이 필요하면 내 컴퓨터(Ollama) 탭을 사용해주세요.

데이터 관리

이 기기에 저장된 설정과 대화 기록을 관리해요. 모든 데이터는 브라우저(localStorage)에만 저장되고, 서버로 전송되지 않아요.
